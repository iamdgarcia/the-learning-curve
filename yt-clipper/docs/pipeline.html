⚡ yt-clipper — Pipeline Architecture

Cómo funciona cada paso del pipeline, qué modelos se usan y qué parámetros controlan cada decisión.

Pipeline completo

①
Transcript Extraction
yt-dlp detecta el idioma del vídeo. Se buscan captions manuales y auto-generadas en ese idioma. Si el vídeo no tiene subtítulos, se descarga el audio completo y se transcribe localmente.
youtube-transcript-api v1 Whisper small (fallback)
②
Two-Agent LLM — Selección de clips
Agent 1 (Finder) propone max_clips × 2 candidatos con justificación y hook. Agent 2 (Reviewer) puntúa 1–10, rechaza <7, ajusta timestamps ±10s y genera título/descripción/tags en el idioma original.
DeepSeek v3 via Novita.ai
③
Download — yt-dlp HLS
Descarga solo el segmento necesario ±10s (padding). Prioriza HLS/m3u8 sobre HTTPS para evitar 403. Selecciona audio en el idioma original del vídeo. Usa cookies de Firefox para bypass de bot-detection.
yt-dlp binary + Firefox cookies
④
Silence Check — Rechazo de aire muerto
ffmpeg silencedetect analiza el segmento. Si más del 40% del clip es silencio ≥-35dB durante ≥1.5s, el clip se rechaza (stream exit, pausa larga). El pipeline pasa al siguiente candidato.
ffmpeg silencedetect
⑤
Frame Analysis — Cara + Zona activa
Muestrea 12 frames del clip. Detecta la cara con Haar Cascade (mediana robusta). Expande al panel webcam cuadrado. Calcula el centroide de movimiento (frame differencing) para saber dónde está el cursor/ratón.
OpenCV Haar Cascade Frame differencing + Gaussian blur
⑥
Audio Enhancement — Noise reduction
Extrae el audio a WAV 44100Hz. Estima el ruido de fondo con los primeros 0.5s. Aplica filtro de Wiener adaptativo en dominio frecuencial (noisereduce). Recombina con el vídeo.
noisereduce v3 (Wiener filter)
⑦
Vertical Conversion — 1080×1920
Un único pase ffmpeg hace todo: trim preciso, crop del panel de cara (cuadrado centrado en la cara), crop de pantalla con zoom ~1.6× centrado en el cursor, vstack de ambos paneles. -t {duration} sincroniza audio y vídeo.
ffmpeg filter_complex + libx264 CRF 18
⑧
Speaker Diarization — Quién habla cuándo
Resemblyzer codifica el audio en embeddings de 256D por ventanas de 1.5s. Estima el número de speakers por similitud coseno. Agglomerative clustering → segmentos por locutor → colores estilo OpusClip.
Resemblyzer GE2E (17M params) AgglomerativeClustering
⑨
Subtítulos TikTok — Word-by-word
Whisper transcribe solo el audio del clip (0..duration, sin drift). Genera eventos ASS con 3 palabras por bloque. La palabra activa se colorea (amarillo, caja naranja, o color del speaker). 4 estilos disponibles.
Whisper small — clip audio ASS subtitle format
⑩
Hook Overlay — Texto animado (3s)
Quema el hook generado por el LLM sobre los primeros 3 segundos del clip. 5 templates de estilo (caja amarilla, barra oscura, texto dorado...). Fade in/out de 0.3s. Auto-wrap a 28 caracteres por línea.
ffmpeg drawtext
⑪
B-Roll — Stock footage IA (opcional)
El LLM extrae 3 keywords visuales del transcript. Pexels API busca vídeos verticales HD. Se descarga el primero disponible y se compone encima del panel de pantalla entre los segundos 5–9 del clip.
DeepSeek v3 (keywords) Pexels API + ffmpeg overlay

⑤ Frame Analysis — Layout vertical

Detección de cara — Haar Cascade

12 frames muestreados
→ por frame: detectMultiScale(scale=1.05, minN=3)
→ minSize = 5% del ancho de frame
→ queda la detección más grande (descarta miniaturas)
→ mediana de todas las hits = bounding box robusto
→ expandir a cuadrado centrado en la cara
→ clamp: panel_h = min(panel_w, frame_h)

Detección de actividad

diff[i] = |frame[i+1] − frame[i]|
heat = mean(diffs)
→ Gaussian blur 31×31 (elimina ruido JPEG)
→ centroide ponderado top 15% de píxeles
→ cx = Σ(x × heat) / Σ(heat)

Output: 1080×1920 — Split dinámico por clip
