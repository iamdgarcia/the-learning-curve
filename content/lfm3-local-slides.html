Option 1 — Easiest

Run LFM3 with Ollama

One command. Ollama downloads the model and opens a chat. No build step.

$
ollama run hf.co/LiquidAI/LFM3-1.7B-GGUF:Q4_K_M
Downloads 1.1 GB on first run · works on CPU · no GPU required

Option 2 — Fastest inference

Run LFM3 with llama.cpp

Step 1 — Build (one-time, ~3 min)
git clone https://github.com/ggml-org/llama.cpp
cd llama.cpp
cmake -B build
cmake --build build --config Release -j$(nproc)
Step 2 — Chat
./build/bin/llama-cli \
  -hf LiquidAI/LFM3-1.7B-GGUF:Q4_K_M \
  --temp 0.1 --top-k 50 \
  --repeat-penalty 1.1 -cnv
💡 Math/science? Use --temp 1.0 --top-p 0.95 --top-k 20 instead

Option 3 — For developers

Run LFM3 with Python

$ pip install llama-cpp-python huggingface_hub
$ python lfm3_chat.py

The script auto-downloads the GGUF on first run and opens a conversation loop. No framework, no LangChain, no boilerplate.

The bigger picture

Why SSM matters for small models

Transformer
❌ Quadratic complexity on long contexts
❌ KV cache grows with sequence length
❌ Memory-hungry at small param counts
✅ Mature ecosystem (llama.cpp, Ollama...)
LFM3 (SSM hybrid)
✅ Linear complexity on long contexts
✅ Fixed-size memory footprint
✅ Competitive at 1.7B vs 3.2B Transformers
✅ GGUF/ONNX/MLX — same tools
