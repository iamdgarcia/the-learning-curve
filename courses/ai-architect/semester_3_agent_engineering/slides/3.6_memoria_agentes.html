Memoria en agentes: los cuatro tipos

Define el ciclo de vida de la información antes de elegir el almacén

chat_bubble In-context · Short-term
arrow_forwardR arrow_backW
Persiste: sesión
Coste: medio
Historial de conversación, herramientas llamadas, output actual
No requiere infraestructura externa
pending_actions Working Memory
arrow_forwardR arrow_backW
Persiste: tarea
Coste: bajo
Progreso de tarea larga: pasos completados, resultados intermedios
Ciclo de vida atado a la tarea
history Episodic Memory
R inicio sesión / W al cerrar
Persiste: indefinido
Coste: medio-alto
Preferencias del usuario, historial de errores, interacciones pasadas
Requiere almacén externo + búsqueda semántica
library_books Semantic Memory (RAG)
Solo R
Persiste: permanente
Coste: bajo/consulta
Documentos de referencia, políticas, procedimientos del dominio
El agente consulta, nunca modifica el conocimiento
smart_toy
AGENTE
R: lectura W: escritura
Pregunta antes de elegir
¿Solo esta sesión? → In-context
¿Tarea larga interrumpible? → Working
¿Historial del usuario? → Episodic
¿Conocimiento del dominio? → Semantic/RAG
warning
