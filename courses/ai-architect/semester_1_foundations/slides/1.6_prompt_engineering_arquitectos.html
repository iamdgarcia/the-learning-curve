security Prompt Injection

El usuario puede enviar instrucciones que el modelo ejecute sobre tu system prompt. Nunca asumas que es inviolable. Diseña asumiendo intentos de subversión.

¿Problema en el prompt o en la arquitectura?

Si cambiar el prompt mejora de forma clara → problema de prompt. Si cambias y mejora marginalmente → problema arquitectural (datos, contexto, capacidades).

code_blocks

Analogía: El system prompt es la definición de interfaz del servicio. El user prompt es la llamada a ese servicio. Interfaz mal definida = comportamiento incorrecto sin importar las llamadas.
