Texto libre vs. JSON tipado — El contrato de salida del LLM

close Sin structured outputs — frágil

Output del LLM (texto libre):

"El precio del producto es 42 euros, incluyendo IVA."

A veces: "EUR 42" · "42,00 €" · "cuarenta y dos euros" · ...

arrow_downward

Tu código intenta parsear:

regex(r"\d+") ← falla en el 20%

bug_report

Fallo silencioso en producción

check_circle Con structured outputs — predecible

Schema definido:

{"precio": number, "incluye_iva": boolean}

arrow_downward

Output garantizado, siempre:

{"precio": 42, "incluye_iva": true}

arrow_downward

Código downstream accede directamente: output.precio

verified

Interfaz tipada. Sin regex. Sin sorpresas.

build

Function Calling — un nivel más

El LLM no solo genera JSON — decide qué herramienta llamar y con qué argumentos. Tu código ejecuta la función real y devuelve el resultado al LLM.

crear_ticket(cliente="García",
prioridad="urgente")
